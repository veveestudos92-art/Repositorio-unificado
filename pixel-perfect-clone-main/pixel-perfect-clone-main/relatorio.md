# 💗 Meu Estilo — Pixel Perfect Clone

## 📌 Sobre o projeto

O **Meu Estilo** é um site interativo desenvolvido com o objetivo de ajudar o usuário a descobrir qual estilo de moda combina mais com sua personalidade e preferências.

O projeto foi desenvolvido como atividade acadêmica, utilizando uma ferramenta de criação de sites com Inteligência Artificial, buscando aplicar conceitos de desenvolvimento web, personalização visual e interatividade.

---

## 🛠️ Ferramenta utilizada

A ferramenta escolhida para o desenvolvimento do projeto foi o **Lovable**, uma plataforma que utiliza Inteligência Artificial para auxiliar na criação de aplicações e páginas web.

### Justificativa da escolha

O Lovable foi escolhido por facilitar o desenvolvimento de interfaces web por meio de comandos em linguagem natural. A ferramenta permite descrever as características desejadas para o projeto e realizar alterações de forma rápida.

Além disso, possibilitou a criação de uma interface moderna e interativa, atendendo aos requisitos propostos para a atividade.

## 🧠 Funcionalidade interativa

A principal funcionalidade interativa desenvolvida no projeto é um **quiz de descoberta de estilo**.

Ao iniciar o quiz, o usuário pode escolher entre:

- 👩 **Quiz Feminino**
- 👨 **Quiz Masculino**

Cada opção apresenta perguntas específicas relacionadas às preferências de moda do usuário.

As perguntas abordam características como:

- Roupas preferidas
- Cores
- Calçados
- Acessórios
- Ocasiões
- Tipos de looks
- Personalidade
- Preferências relacionadas ao estilo

## ⚙️ Funcionamento do sistema de resultados

Para evitar que todos os usuários recebam o mesmo resultado, cada resposta do quiz está relacionada a um determinado estilo.

Durante o preenchimento do questionário, o sistema contabiliza pontos para os estilos correspondentes às respostas escolhidas.

Ao finalizar o quiz:

1. O sistema analisa as respostas;
2. Os pontos de cada estilo são contabilizados;
3. O estilo com maior pontuação é identificado;
4. O resultado correspondente é apresentado ao usuário.

Dessa forma, diferentes combinações de respostas podem gerar diferentes resultados.

- 🏠 Voltar para a página inicial

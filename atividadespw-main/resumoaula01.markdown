O controle de versões é responsável por registrar todas as alterações feitas em um projeto.

- 💾 Recuperar versões anteriores;
- 👥 Facilitar o trabalho em equipe;
- 🌿 Utilizar branches para desenvolvimento paralelo.

Também foram apresentados alguns sistemas de versionamento:

- GitHub
- GitLab
- Bitbucket

Além disso, foi introduzido o conceito de **Deploy** e de **Integração Contínua (CI/CD)**.

# 💛 JavaScript (Vanilla JS)

JavaScript é uma linguagem de script interpretada utilizada no desenvolvimento front-end.

**Vanilla JS** significa utilizar JavaScript puro, sem frameworks ou bibliotecas.

Sua principal função é tornar as páginas interativas, permitindo manipulação dos elementos da interface e comunicação com servidores.

# 🖥️ Website Builders

São ferramentas que permitem criar sites sem necessidade de programação manual.

### ✅ Vantagens

- 😊 Fácil utilização;
- ⚡ Desenvolvimento rápido;
- 💰 Bom custo-benefício;
- 📱 Templates responsivos.

### ⚠️ Limitações

- 🔒 Menor flexibilidade;
- 🐢 Possível perda de desempenho;
- 🔄 Migração mais difícil.

# 💼 Dica Importante

O professor ressaltou a importância de manter um **portfólio** de projetos, pois ele demonstra habilidades práticas, facilita a avaliação do aprendizado e pode abrir oportunidades de estágio e emprego.

---

# 📝 Critérios de Avaliação

A nota será composta por:

- 📄 P1 → 25%
- 📄 P2 → 25%
- 💻 Projeto (PJ)
- 📚 Atividades (AT)

**Fórmula:**

```text
(P1 × 0,25) + (P2 × 0,25) + ((PJ + AT) × 0,25)
```

---

# 🚀 Atividade da Aula

- 👥 Formar grupos de 3 a 5 integrantes;
- 💡 Definir uma ideia de projeto;
- 📂 Criar um repositório no GitHub;
- 📝 Elaborar um resumo da Aula 01 em Markdown;
- 🔍 Escolher três sites, identificar suas tecnologias e montar uma análise no Miro.
